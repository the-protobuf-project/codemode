# @the-protobuf-project/codemode

The runtime for code generated by
[`protoc-gen-codemode`](https://github.com/the-protobuf-project/codemode):
protojson and binary codecs, HTTP and Connect transports, sandboxed executors,
and the durable Code Mode runtime with approvals, replay, rollback and snippets.

| Entry point | Contents |
| --- | --- |
| `@the-protobuf-project/codemode` | Codecs, well-known types, transports, connectors, `createCodemode`, stores |
| `/quickjs` | `QuickJSExecutor`: Node, Bun, Deno, browsers |
| `/deno` | `DenoExecutor`: a permissionless Deno process per pass |
| `/cloudflare` | `WorkerLoaderExecutor`, Durable Object SQL, `cloudflareTools` |
| `/browser` | `IframeExecutor` |
| `/mcp` | `createMcpServer` |
| `/ai` | `codemodeTool` for the Vercel AI SDK |

See the [runtime documentation](https://github.com/the-protobuf-project/codemode/blob/main/docs/runtime.md).
